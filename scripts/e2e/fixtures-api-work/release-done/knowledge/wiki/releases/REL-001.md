## Endpoints
- `GET /api/v1/reviews/:reviewId/summary` returns the review summary of a finished review as a PDF. Request body: none. Response body: `ReviewSummary` (200). Errors: 401 (not signed in), 403 (not the reviewer who wrote the review), 404 (unknown review), 409 (the review is not finished).

## Data models
### ReviewSummary
- `fileName`: string, for example `review-summary.pdf`
- `contentType`: `application/pdf`
- `content`: the PDF bytes of one A4 page

## Authentication requirements
Bearer token of the signed-in reviewer. Only the reviewer who wrote the review may request its summary.

## Notes
The summary is generated when it is requested. Nothing is stored.
